# 驗證紀錄

日期：2026-10-24。版本：課堂探究模式 1.0。

## 自動化檢查

- Node 測試：原探究單 A/B/C/D 數據、固定果汁加水、等比例放大、零水與非法數值、檸檬紅茶、25% 與購買瓶數。
- 課程結構：12 頁、五階段、唯一 id，開場問題與後續提示分離，示範課資產與來源一致。
- Python 產生器測試：review/inquiry 兩模式、五階段骨架、HTML 標題轉義、禁止無意覆寫、離線驗證。
- 本機 Chrome：猜想輸入、原生鍵盤操作、固定量鎖定、滑桿變化、快照不隨配方變動、跨頁及重新整理保存、逐層提示、引用證據、學生文字安全呈現、瓶數核對、JSON 匯出、重設。
- 響應式：1440×1000 桌面、390×844 手機，無整頁水平溢出，選擇目錄後側欄關閉。

以 `node --test tests/model.test.cjs tests/schema.test.cjs`、`python tests/generator_test.py`、`node tests/browser.cjs` 重跑。瀏覽器測試前先啟動 HTTP 伺服器；需要 Playwright 及 Chromium 或 Chrome，詳見 README。

## 人工檢視與限制

檢視實驗台、論證頁及手機畫面。保留大字體與頁內捲動；單頁資料量較大時需向下捲動。

本機瀏覽器驗證不代表已在 Safari、iOS 真機或所有投影尺寸驗證。畫筆與雷射筆沿用上游，需依授課設備確認實際觸控體驗。CI 的遠端結果以 GitHub Actions 為準，不把本機通過視為遠端已通過。

`verify_deck.js` 對探究頁只驗證結構，不啟動真實 DOM。上游複習驗證器滑桿掃描最多 81 次，不保證掃到所有值或多滑桿組合。數學解釋與論證品質仍需教師覆核。

## 維護流程

改 `assets/` 或課程來源後，先 `python scripts/build_demo.py`，再跑相關測試。未修改的部分不必反覆執行。新增頁型需更新 schema、文件與有代表性的瀏覽器操作驗證。
